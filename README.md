# STARFALL: VOID FRONTIER

**2497 / The Reach.** Вы — вольный капитан: старый корабль, работа, опасная дорога и собственные решения. Игра проходит переработку в SPACE STORY GENERATOR по [канону](LORE_BIBLE.md) и [плану](REWORK_PLAN.md). Полная новая симуляция экипажа/мира ещё не завершена; [PROGRESS.md](PROGRESS.md) перечисляет фактическое состояние.

[**Играть в браузере →**](https://epictouch22.github.io/STARFALL-VOID-FRONTIER/)

Одиночная космическая survival/RPG: аварийный корабль, полёт с инерцией, посадки, добыча, работа, торговля и медицина. Пелена и Решётка остаются загадками; Хор — человеческое явление, происхождение которого не доказано. Пять региональных угроз и локальные решения по сети доступны как необязательное исследование.

## Запуск

Node.js 22.12+ (или 24+).

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Для браузерных проверок: `npx playwright install chromium webkit`, затем `npm run test:browser` в другом терминале при запущенном production preview. Проверяется обычный путь от New Game через ремонт, физическую стыковку, сотрудников станции, работу инженера, сохранение/загрузку, вылет и межсистемную доставку в Chromium и WebKit с размером экрана iPhone.

В dev/preview открывайте `/STARFALL-VOID-FRONTIER/`. `dist` — полностью статический production build. Backend, регистрация и загрузка внешних ассетов не нужны. Графика создаётся Canvas, звуки — Web Audio после первого касания.

## Управление

| Действие                         | ПК                                         | Телефон            |
| -------------------------------- | ------------------------------------------ | ------------------ |
| Движение                         | WASD / стрелки                             | Левый стик         |
| Наведение и огонь                | Мышь + пробел / правая кнопка              | Правый стик        |
| Действие                         | E                                          | Контекстная кнопка |
| Сканер                           | R                                          | «Сканер»           |
| Форсаж / тормоз                  | Shift / X                                  | Кнопки             |
| Карта / груз / медицина / журнал | G / I / M / J                              | Нижняя панель      |
| Пауза / настройки                | Esc                                        | Меню               |
| Автопилот                        | Нажать объект или выбрать контакт на карте | Касание объекта    |

Старт: найдите инструменты у верстака справа внизу, почините шлюз, реактор и двигатель, затем идите в кабину. Для стыковки опознайте порт сканером, запросите разрешение на карте, направьте нос налево, снизьте скорость до <12 м/с и приблизьтесь к захватам на 22 м. Автопилот выравнивает корабль. После захвата дождитесь герметизации/давления, встаньте из кресла, пройдите через корабельный шлюз и станционную дверь. В Порту выберите сотрудника: капитан физически идёт по коридорам. Магазин/контракты/инженер/врач работают только рядом с ними. Для вылета вернитесь, закройте обе двери, сядьте и отпустите захваты. На поверхности подойдите к объекту и нажмите действие. Для взлёта вернитесь к модулю.

Три слота сохраняются в localStorage. Автосохранение каждые 30 секунд, при переходах и уходе в фон. Настройки позволяют экспортировать и импортировать JSON. Контрольная сумма, проверка вложенных данных и предыдущая исправная копия защищают от повреждения. Формат 6 автоматически мигрирует сохранения форматов 1–5, сохраняя условия уже принятых старых контрактов. Экспортируйте копию перед очисткой браузера; сохранения локального dev-сайта и GitHub Pages независимы.

У скафандра отдельный контейнер на 35 кг / 12 слотов. Добыча на поверхности попадает туда; при взлёте ресурсы выгружаются на корабль, если есть место. Переносите предметы кнопками в меню груза. Четыре быстрых слота работают через клавиши 1–4 или кнопки в инвентаре. «К модулю» возвращает к месту посадки. Обездвиженный пиратский корабль можно взять на абордаж; на заброшенных кораблях охрана защищает груз. Наружный ремонт выполняется в скафандре рядом со своим кораблём.

Контракты доставки и перевозки пассажиров ведут в конкретный порт другой системы. Груз выдаётся при принятии, занимает место и защищён от расходования. «Маршрут» открывает цель на карте; в нужной системе включает автопилот. Спасение экипажа требует абордажа, победы над охраной, взаимодействия с центральным терминалом и возвращения людей в исходный порт. Отмена в порту освобождает место и снижает репутацию.

Охрана конвоя: корабль «Светляк» следует за вами и принимает урон от пиратов. Перед гиперпрыжком приблизьтесь к нему на 250 м. Доведите корабль до безопасной зоны указанного порта и сдайте контракт. Потеря конвоя означает провал и −8 репутации. Корпус конвоя виден в HUD, мире и на радаре.

## Deployment

Каждый push в `main` запускает `.github/workflows/deploy.yml`: `npm ci`, unit/integration tests, production build, проверку asset paths, браузерные acceptance tests, upload Pages artifact и deploy. Vite `base` установлен в `/STARFALL-VOID-FRONTIER/`. JS/CSS используют этот префикс; изображения и звук генерируются без сетевых путей. GitHub Pages настроен на источник **GitHub Actions**.

## Модули и расширение

- `src/data/catalog.ts`: предметы, рецепты, биомы, корабли, технологии, события и главы. Добавляйте предмет с уникальным ID, весом, ценой и описанием; для используемого предмета добавьте действие в `actions.ts`/`medicine.ts`.
- `src/world/galaxy.ts`: PRNG, галактика и поверхность. Новые биомы добавляются в `biomes`, генерация выбирает их по seed. Не меняйте алгоритм без плана миграции уже сохранённых миров.
- `src/core/types.ts`, `state.ts`: сериализуемое состояние. `simulation.ts`: фиксированный шаг физики, AI, бой, аварии. `actions.ts`: переходы, сканирование, добыча и сюжет.
- `src/core/economy.ts`: цены, торговля, контракты. Для задания добавьте тип и проверяемые условия в `contractOffers`/`claimContract`; новые виды прогресса обновляются при игровых событиях.
- `src/data/catalog.ts`: технологии имеют уникальный `effect`; добавьте реальный эффект в `shipStats`, `tick`, действия или интерфейс. Требования задаются `requires` и `region`.
- `src/scenes/renderer.ts`: процедурное изображение текущей локации. `src/input`: клавиатура и pointer controls. `src/ui`: HTML-терминалы и HUD. `src/audio`: синтез.
- `src/save/storage.ts`: формат 6, миграция из форматов 1–5, checksum, валидация и резервные копии. При изменении формата добавляйте явную миграцию перед проверкой.
- `tests/rules.test.ts`: генерация, инвентарь, медицина, бой, экономика, технологии, сохранения и порядок кампании.

Typecheck, 76 unit/integration tests и production build проверяют правила. Отдельный earned-campaign тест сохраняет совместимость прежней пятиглавной кампании; production browser проверяет текущую физическую экспедицию без debug и изменения сохранений.

Читайте `PROGRESS.md` для проверенного объёма релиза и оставшихся задач. Исходный большой brief ещё не покрыт во всей глубине: экипаж, рассказчики и связанные истории, экономика мира, отдельные пещеры, жидкости и захват кораблей остаются развитием проекта.

## Совместимость

Production target — Safari 15+. Интерфейс учитывает iPhone safe area, кнопки не требуют hover, стик использует Pointer Events. Ограничен pixel ratio, текущая система симулируется отдельно, меню и фон приостанавливают игру. Проверка WebKit в автоматизации не заменяет тест реального iPhone.

Радиосигналы: сканируйте обломки/аномалии, затем откройте Журнал → Сигналы. Ответ можно отложить. Маяк требует подойти на 300 м и свободного грузового отсека; выбор сразу сохраняется. Ремонт и исследование в новой экспедиции занимают время: оставайтесь рядом, повторное E отменяет работу.
